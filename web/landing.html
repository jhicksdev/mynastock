One kernel, three hosts

The ledger rules, router, handlers, and invariants are import-free shared code. The same files run under the stdlib server, the ASGI adapter, and the browser demo.

A ledger, not a spreadsheet

Movements are append-only. Balances are a materialized fold updated in the same transaction, with idempotent posting and optimistic version checks.

Zero-install delivery

myna bundle --zipapp produces a 22 KB archive that runs on a clean Python. No pip, no venv, no services.

The language

Dense source. Ordinary Python.

Myna is a surface syntax over Python semantics. This is a real function from the ledger:

See the transpiled output

+@plan_issue(level:StockLevel?,pid:s,lid:s,qty:i,now:s)->Result{
  e=check_qty(qty)
  ?e!==N{^Result(F,N,e)}
  have=on_hand_of(level)
  ?level===N||have<qty{
    ^fail("stock.insufficient","Not enough stock", "qty",{available:have})
  }
  ^ok(Plan([Leg(lid,-qty,avg_of(level))],
     [next_level(level,pid,lid,have-qty,avg_of(level),now)]))
}
